## ক. নিজের পরিচয় ও আচরণগত প্রশ্ন (৫টি)

**১. নিজের সম্পর্কে বলুন।**
আমি মো. সোহেল রানা। আমি বরেন্দ্র বিশ্ববিদ্যালয় থেকে Computer Science and Engineering-এ B.Sc. complete করেছি। গত কয়েক বছর ধরে Full Stack Technology নিয়ে Explore করেছি এবং সেই জ্ঞান কাজে লাগিয়ে বিভিন্ন Project Build করেছি। বর্তমানে আমি নতুন যা শিখি, তা আমার Engineering-Notebook নামক Repository-তে Document করে রাখি, যাতে ভবিষ্যতে সেগুলো কাজে লাগিয়ে আমার Productivity বৃদ্ধি করতে পারি।

**২. কেন BSD-তে কাজ করতে চান?**
JD-তে দেখেছি আপনারা কোড কপি করা মানুষ চান না, বরং সমস্যা বুঝে প্রশ্ন করা মানুষ চান। এটা আমার কাজের ধরনের সাথে মেলে। এছাড়া আপনাদের টিম বিভিন্ন স্ট্যাকে কাজ করে, যা আমাকে দ্রুত শিখতে সাহায্য করবে। আমি ঢাকায় অফিসে সম্পূর্ণ অনসাইট কাজ করতে প্রস্তুত।

**৩. আপনার সবচেয়ে বড় শক্তি ও দুর্বলতা কী?**
শক্তি: নিজে শেখার ক্ষমতা ও প্রজেক্ট শেষ পর্যন্ত নিয়ে যাওয়া। দুর্বলতা: unit testing ও CI/CD-তে অভিজ্ঞতা নেই, আর অনলাইন জাজে সক্রিয় নই। এগুলো শেখা শুরু করার পরিকল্পনা আছে।

**৪. একটি কঠিন সমস্যা কীভাবে সমাধান করেছেন?**
এখানে নিজের একটি বাস্তব বাগ বলুন (যেমন refresh token বা payment flow-এর সমস্যা)। কাঠামো: সমস্যা কী ছিল, কীভাবে খুঁজে বের করলাম, কী সমাধান করলাম, কী শিখলাম।

**৫. আপনি কি এখনই জয়েন করতে পারবেন? বেতনের প্রত্যাশা কত?**
জয়েনিং: পরীক্ষা বা অন্য বাধ্যবাধকতা না থাকলে দ্রুত জয়েন করতে পারব। বেতন: ফ্রেশার হিসেবে কোম্পানির স্কেল অনুযায়ী যা যুক্তিসঙ্গত তা মেনে নেব, শেখা ও বেড়ে ওঠাই আমার অগ্রাধিকার।

## গ. প্রজেক্ট ডিপ-ডাইভ (৮টি)

**১০. Mini Kanban Board-এর আর্কিটেকচার ব্যাখ্যা করুন।**
ফ্রন্টএন্ডে Next.js, ব্যাকএন্ডে Express.js, ডাটাবেস PostgreSQL, ORM হিসেবে Prisma, আর Docker দিয়ে কন্টেইনারাইজড ডেভেলপমেন্ট। ব্যাকএন্ডে layered architecture ব্যবহার করেছি।

**১১. Kanban-এ authentication কীভাবে কাজ করে?**
Access ও refresh token ব্যবহার করেছি, দুটোই HTTP-only cookie-তে। Access token মেয়াদ শেষ হলে refresh token দিয়ে নতুন access token নেওয়া হয়। এতে XSS থেকে টোকেন চুরির ঝুঁকি কমে।

**১২. Optimistic update কী এবং কেন ব্যবহার করেছেন?**
সার্ভার রেসপন্সের আগেই UI আপডেট দেখানো হয় (যেমন কার্ড ড্র্যাগ করলে সাথে সাথে সরে যায়)। সার্ভারে ব্যর্থ হলে আগের অবস্থায় ফেরত নেওয়া হয়। এতে অ্যাপ দ্রুত মনে হয়। (সতর্কতা: কোন ডেটা-ফেচিং লাইব্রেরি, TanStack Query না RTK Query, ব্যবহার করেছেন সেটা CV অনুযায়ী নিশ্চিত করে বলুন।)

**১৩. Pharmaciano প্রজেক্টটি কী সমস্যা সমাধান করে?**
মাল্টি-ব্রাঞ্চ ফার্মেসির ইনভেন্টরি, ব্যাচ ও মেয়াদ ট্র্যাকিং, ক্রয়, বিক্রয় ও ইনভয়েসিং। Gemini API দিয়ে চাহিদা পূর্বাভাসও আছে।

**১৪. Pharmaciano-তে role-based access কীভাবে বানিয়েছেন?**
JWT দিয়ে ইউজার চেনা হয়, তারপর middleware রোল ও পারমিশন যাচাই করে রুট চালাতে দেয়। ইনপুট যাচাইয়ে Zod ব্যবহার করেছি।

**১৫. Pharmaciano-তে Redis কেন ব্যবহার করেছেন?**
ঘনঘন পড়া হয় এমন API রেসপন্স ক্যাশ করতে, যাতে ডাটাবেসে চাপ কমে ও রেসপন্স দ্রুত হয়। ক্যাশ ইনভ্যালিডেশন (ডেটা বদলালে পুরোনো ক্যাশ মুছে ফেলা) গুরুত্বপূর্ণ।

**১৬. E-Book Application-এ payment flow কেমন?**
SSLCommerz ইন্টিগ্রেট করেছি। পেমেন্ট সফল হলে ইউজারকে বইয়ের PDF-এ প্রবেশাধিকার দেওয়া হয়, আর কেনা না থাকলে অ্যাক্সেস বন্ধ থাকে।

**১৭. E-Book-এ Socket.IO কোথায় ব্যবহার করেছেন, আর পরে কী উন্নত করতেন?**
যেখানে রিয়েল-টাইম আপডেট দরকার সেখানে ব্যবহার করেছি। উন্নতির দিক: unit/integration টেস্ট যোগ করা, CI/CD সেট করা, আর ক্যাশিং ও এরর হ্যান্ডলিং আরও শক্ত করা।

## ঘ. JavaScript / TypeScript (৬টি)

**১৮. `var`, `let`, `const`-এর পার্থক্য কী?**
`var` function-scoped ও hoisted। `let` ও `const` block-scoped। `const`-এ পুনঃনিয়োগ করা যায় না, তবে অবজেক্টের ভেতরের মান বদলানো যায়।

**১৯. Closure কী?**
কোনো ফাংশন তার বাইরের স্কোপের ভ্যারিয়েবল মনে রাখে, এমনকি বাইরের ফাংশন শেষ হয়ে গেলেও।

**২০. Promise, async/await ও callback-এর পার্থক্য কী?**
Callback হলো ফাংশন পাঠিয়ে দেওয়া (nested হলে callback hell)। Promise ভবিষ্যতের ফলাফলের প্রতিনিধিত্ব করে। async/await Promise-কে সিঙ্ক্রোনাস কোডের মতো পড়ার উপযোগী করে।

**২১. Event loop কীভাবে কাজ করে?**
JavaScript সিঙ্গেল-থ্রেডেড। Call stack খালি হলে event loop প্রথমে microtask queue (Promise), পরে macrotask queue (setTimeout) থেকে কাজ তুলে আনে।

**২২. `==` ও `===`-এর পার্থক্য কী?**
`==` টাইপ কনভার্ট করে তুলনা করে, `===` টাইপসহ তুলনা করে। সবসময় `===` ব্যবহার করা ভালো।

**২৩. TypeScript কেন ব্যবহার করেন? `interface` ও `type`-এর পার্থক্য কী?**
কম্পাইল টাইমে ভুল ধরা পড়ে, কোড নিরাপদ ও ডকুমেন্টেড হয়। `interface` মূলত অবজেক্টের গঠন বোঝায় এবং extend করা যায়। `type` union, intersection ইত্যাদি আরও নমনীয়ভাবে প্রকাশ করতে পারে।

## ঙ. Node.js, Express, REST, HTTP, Auth (৬টি)

**২৪. REST API কী?**
HTTP মেথড (GET, POST, PUT/PATCH, DELETE) দিয়ে রিসোর্সের উপর কাজ করার একটি স্থাপত্যশৈলী। এটি stateless।

**২৫. HTTP স্ট্যাটাস কোডের গুরুত্বপূর্ণ উদাহরণ দিন।**
200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Internal Server Error।

**২৬. Middleware কী?**
রিকোয়েস্ট ও রেসপন্সের মাঝখানে চলা ফাংশন, যেমন auth যাচাই, লগিং, ভ্যালিডেশন বা এরর হ্যান্ডলিং।

**২৭. JWT কীভাবে কাজ করে?**
লগইনের পর সার্ভার ইউজারের তথ্যসহ স্বাক্ষরিত টোকেন দেয়। প্রতি রিকোয়েস্টে ক্লায়েন্ট সেটি পাঠায়, সার্ভার স্বাক্ষর যাচাই করে। টোকেনে পাসওয়ার্ডের মতো সংবেদনশীল তথ্য রাখা উচিত নয়।

**২৮. এরর হ্যান্ডলিং কীভাবে করেন?**
`try/catch` ও একটি কেন্দ্রীভূত error middleware ব্যবহার করি, যাতে সব API একই ফরম্যাটে এরর রেসপন্স দেয়।

**২৯. 401 ও 403-এর পার্থক্য কী?**
401: ইউজার লগইন করেনি বা টোকেন অবৈধ। 403: ইউজার লগইন করা আছে, কিন্তু এই কাজের অনুমতি নেই।

## চ. SQL, ডাটাবেস ডিজাইন, PostgreSQL/Prisma (৫টি)

**৩০. Primary key ও foreign key কী?**
Primary key প্রতিটি রো-কে অনন্যভাবে চিহ্নিত করে। Foreign key অন্য টেবিলের primary key-কে নির্দেশ করে সম্পর্ক তৈরি করে।

**৩১. JOIN-এর ধরনগুলো কী কী?**
INNER JOIN (দুই টেবিলে মিল আছে এমন রো), LEFT JOIN (বাম টেবিলের সব রো ও ডান টেবিলের মিলগুলো), RIGHT JOIN, FULL JOIN।

**৩২. Index কী এবং কেন ব্যবহার করেন?**
Index কলামের উপর অনুসন্ধান দ্রুত করে। তবে লেখার সময় একটু ধীর করে ও জায়গা নেয়, তাই শুধু ঘনঘন খোঁজা কলামে দিতে হয়।

**৩৩. Normalization কী?**
ডেটার পুনরাবৃত্তি কমাতে ও সামঞ্জস্য বজায় রাখতে টেবিল ভেঙে সাজানো (1NF, 2NF, 3NF)।

**৩৪. Prisma migration কী?**
স্কিমার পরিবর্তনকে ভার্সন-নিয়ন্ত্রিত SQL ফাইলে রেকর্ড করে ডাটাবেসে প্রয়োগ করার পদ্ধতি। এতে টিমের সবার ডাটাবেস একই অবস্থায় থাকে।

## ছ. OOP, DSA ও লজিক (৫টি)

**৩৫. OOP-এর চার স্তম্ভ কী?**
Encapsulation, Abstraction, Inheritance, Polymorphism। প্রতিটির একটি ছোট উদাহরণ ভেবে রাখুন।

**৩৬. Array ও Linked List-এর পার্থক্য কী?**
Array-তে ইনডেক্স দিয়ে O(1) অ্যাক্সেস, কিন্তু মাঝখানে ঢোকানো ধীর। Linked List-এ ঢোকানো/মোছা সহজ, কিন্তু র‍্যান্ডম অ্যাক্সেস O(n)।

**৩৭. Stack ও Queue-এর পার্থক্য কী?**
Stack: LIFO (শেষে ঢুকলে প্রথমে বের হয়)। Queue: FIFO (প্রথমে ঢুকলে প্রথমে বের হয়)।

**৩৮. Binary search কীভাবে কাজ করে? Time complexity কত?**
সাজানো অ্যারের মাঝখান দেখে প্রতিবার অর্ধেক বাদ দিয়ে খোঁজা। জটিলতা O(log n)।

**৩৯. লজিক সমস্যা: একটি স্ট্রিং palindrome কি না যাচাই করুন।**
দুই প্রান্ত থেকে দুটি পয়েন্টার নিয়ে মেলাতে মেলাতে মাঝের দিকে যান। অমিল পেলে false, না পেলে true। জটিলতা O(n)। কথা বলে বলে চিন্তার ধাপ দেখান, কারণ ওরা প্রক্রিয়া দেখতে চায়।

## জ. React / Next.js (৩টি)

**৪০. Virtual DOM কী?**
UI-র হালকা কপি। অবস্থা বদলালে React নতুন ও পুরোনো ভার্সনের পার্থক্য (diffing) বের করে শুধু দরকারি অংশ আসল DOM-এ আপডেট করে।

**৪১. `useEffect`, `useMemo`, `useCallback` কখন ব্যবহার করেন?**
`useEffect`: সাইড ইফেক্টের জন্য (ডেটা ফেচ, সাবস্ক্রিপশন)। `useMemo`: ভারী হিসাবের ফল মনে রাখতে। `useCallback`: ফাংশনের রেফারেন্স স্থির রাখতে।

**৪২. SSR ও SSG-এর পার্থক্য কী?**
SSG: বিল্ড টাইমে পেজ তৈরি হয়, দ্রুত ও ক্যাশযোগ্য। SSR: প্রতি রিকোয়েস্টে সার্ভারে তৈরি হয়, ডায়নামিক ডেটার জন্য ভালো। E-Book-এ আমি দুটোই ব্যবহার করেছি।

## ঝ. PHP / Laravel-এর মৌলিক বিষয় (৩টি)

**৪৩. Laravel কি আপনি ব্যবহার করেছেন?**
সৎ উত্তর: Laravel-এ প্রজেক্ট করিনি, তবে PHP ও MySQL দিয়ে একটি প্রজেক্ট বানিয়েছি। MVC, routing ও ORM-এর ধারণা আমার Express ও Prisma অভিজ্ঞতার সাথে মেলে, তাই দ্রুত শিখে নিতে পারব।

**৪৪. MVC কী?**
Model (ডেটা ও ব্যবসায়িক নিয়ম), View (UI), Controller (রিকোয়েস্ট সামলে Model ও View-কে সংযুক্ত করে)।

**৪৫. Laravel-এর Eloquent ও Express-এ Prisma-এর মিল কোথায়?**
দুটোই ORM: ডাটাবেস টেবিলকে কোড-অবজেক্ট হিসেবে ব্যবহার করতে দেয় ও মাইগ্রেশন সাপোর্ট করে।

## ঞ. Git, Docker, ডিপ্লয়মেন্ট (২টি)

**৪৬. `git merge` ও `git rebase`-এর পার্থক্য কী?**
Merge দুই ব্রাঞ্চের ইতিহাস জুড়ে নতুন merge commit বানায়। Rebase কমিটগুলো অন্য ব্রাঞ্চের উপরে নতুন করে বসিয়ে সরল ইতিহাস তৈরি করে।

**৪৭. Docker কেন ব্যবহার করেন?**
অ্যাপ ও তার নির্ভরতা একটি কন্টেইনারে প্যাকেজ করা যায়, ফলে "আমার মেশিনে চলে" সমস্যা থাকে না। Kanban প্রজেক্টে ডেভেলপমেন্টের জন্য ব্যবহার করেছি।
